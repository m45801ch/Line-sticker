# 🚀 Gemini AI 貼圖助手 (Line Sticker Assistant)

一個專為生成與快速處理 LINE 貼圖設計的 AI 整合工具。本工具不僅能生成高品質 Prompts，更具備強大的「去浮水印」與「智慧去背裁切」功能，幫助您從 AI 繪圖到打包成品一氣呵成。

## ✨ 全新升級功能

### 1. 🎨 AI 提示詞生成器 (Step 1)
- **結構優化**：專利級 Prompt 結構，確保角色一致性與 4x3 網格排版。
- **高度自訂**：可選擇畫風、表情主題、字型顏色，一鍵複製即可使用。

### 2. 🛡️ 批量去浮水印 (Step 2)
- **批量處理**：支援多圖同時上傳，流暢的進度條回饋。
- **高精準還原**：利用反向混色技術 (Reverse Alpha Blending)，乾淨移除 Gemini 等 AI 水印。
- **預覽互動**：支援「燈箱預覽」與懸停「放大鏡」游標，方便檢查細節。
- **靈活下載**：可選擇「打包下載結果 (ZIP)」或針對單張圖片單獨下載。

### 3. ✂️ 智慧型裁切與去背 (Step 3)
- **雙模式裁切**：
    - **4x3 網格**：自動分割 AI 產出的 12 格角色圖。
    - **單格自由裁切**：自由調整位置與縮放，精準擷取所需範圍。
- **專業級去背**：
    - **Chroma Key 演算法**：自定義背景色去背。
    - **溢色去除 (Despill)**：解決綠幕反射問題，讓邊緣與背景完美融合。
- **預覽環境切換**：新增背景色選擇器 (預設、白、黑、藍、粉)，模擬各種應用環境。
- **單圖下載**：去背完成後可直接下載單格透明圖檔。

### 4. 📦 一鍵打包下載 (Step 4)
- 自動生成符合 LINE  Creators Market 規格：
    - **Stickers (N張)**：370 x 320 px
    - **Main (主要圖)**：240 x 240 px
    - **Tab (標籤圖)**：96 x 74 px
- 優化導出邏輯，處理完成後自動歸檔。

## 🛠️ 技術特色
- **純瀏覽器處理**：利用 HTML5 Canvas API 在本地端運算，確保隱私且快速。
- **現代美學 UI**：採用深色模式 (Dark Mode) 與玻璃擬態 (Glassmorphism) 設計，操作體驗流暢。
- **高效架構**：循序處理大圖，避免記憶體溢位，最高支援 20+ 張圖批次操作。

## 🚀 快速上手

1. **安裝環境**
   ```bash
   npm install
   ```

2. **啟動開發**
   ```bash
   npm run dev
   ```

3. **操作流程**
   - **Step 1**: 取得 Prompt 並至 AI 繪圖生成 4x3 貼圖。
   - **Step 2**: 將生成後的圖批次「去浮水印」並下載。
   - **Step 3**: 將去完水印的圖上傳進行「裁切與去背」。
   - **Step 4**: 標註封面圖後，下載完整的 ZIP 壓縮包。
